Payload classifier

Paste a suspicious string — a WAF block-log entry, a request parameter you're unsure about, anything from server logs — and get a classification: benign, SQL injection, XSS, command injection, path traversal, or SSTI. Runs entirely locally; nothing is sent anywhere. Trained on ~233k labeled payloads (Kaggle dataset), ~99.7% accuracy on held-out test data — weakest on command injection using less-common syntax like $(...) or &&, so treat a "benign" verdict on something that still looks suspicious with skepticism.
